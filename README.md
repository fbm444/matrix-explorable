# The Matrix Arcade

A Visual Explorable of Matrices and Linear Transformations.

## About this fork

This is a fork of [The Matrix Arcade](https://github.com/yizhe-ang/matrix-explorable) by [Yizhe Ang](https://github.com/yizhe-ang), who created the original explorable and deserves full credit for its design and implementation. The only change in this fork is one new feature: an added set of sections that **visualize the determinant** — what it measures (the signed area of the transformed unit square), an interactive try-it-out with a live determinant readout, and how the determinant relates to invertibility. Everything else is the original author's work.
